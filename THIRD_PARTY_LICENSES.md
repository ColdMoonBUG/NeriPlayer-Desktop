# 第三方许可引用 / Third-Party License References

## 中文

NeriPlayer Desktop 按根目录的 [GPL-3.0-or-later 许可证](LICENSE) 发布；2026-10-07 之前按 MIT 发布的代码保留
[原声明](LICENSES/MIT.txt)。

本文记录直接引入、改编或随应用分发的源码与资源，不是 Cargo / npm 依赖、字体和其他素材的完整清单。
这些组件遵循各自的版权和许可证声明，以组件自带的声明为准。完整依赖可在 `src-tauri/` 下用 `cargo metadata`、
在仓库根目录用 `pnpm licenses list` 查看。

### 源码与子模块

- [NeriPlayer Android](https://github.com/cwuom/NeriPlayer) 的 DSP 核心
  - 位置：[`src-tauri/crates/neri-playback/native/dsp/`](src-tauri/crates/neri-playback/native/dsp/README.md)
  - 引用：均衡、音色、空间与动态处理的 C++ 实现，来源提交与桌面扩展见该目录 README
  - 许可：GPL-3.0，见目录内 [LICENSE](src-tauri/crates/neri-playback/native/dsp/LICENSE)；不采用上游 USB 路径的替代授权
- [FFmpeg](https://ffmpeg.org/) 公共头文件与共享库
  - 位置：[`src-tauri/crates/neri-playback/native/ffmpeg/include/`](src-tauri/crates/neri-playback/native/ffmpeg/README.md)（头文件）；共享库只随安装包分发
  - 许可：LGPL-2.1-or-later，以每个头文件的声明为准；共享库未启用 GPL / nonfree 组件，Release 附对应源码与构建脚本
- [yt-dlp/ejs](https://github.com/yt-dlp/ejs) 生成的 challenge 求解脚本
  - 位置：[`src-tauri/crates/neri-platform/src/api/youtube/assets/`](src-tauri/crates/neri-platform/src/api/youtube/assets/README.md)
  - 许可：Unlicense；捆绑的 Meriyah 为 ISC，Astring 为 MIT，以文件头部声明为准
- [applemusic-like-lyrics (AMLL)](https://github.com/cwuom/applemusic-like-lyrics)
  - 位置：Git 子模块 `vendor/applemusic-like-lyrics`，构建时打包进前端产物
  - 许可：AGPL-3.0，见子模块内 `LICENSE`
- [YAQMC/qm-api-rs](https://github.com/YAQMC/qm-api-rs)（crate 名 `qqmusic-api`）
  - 位置：`src-tauri/Cargo.toml` 的 `[workspace.dependencies]`，git 依赖固定到提交
    `75f6e4d392f6d3e64608fb48e2480fb0087009e3`，由 `neri-platform` 与宿主 crate 使用
  - 引用：QQ 音乐与微信 OAuth 的协议实现、凭证续期、歌单／曲库读取、取流签名均在库内；
    本仓库侧只有授权窗口编排、导航白名单、回调校验与续期调度
  - 许可：GPL-3.0-or-later；库内含 QMCDecode（作者程序猿老龚）等 MIT 许可的衍生部分，
    来源映射见该仓库 THIRD_PARTY_NOTICES.md
  - 分发：二进制发布时按 GPLv3 第 6 条随附该固定提交的完整源码归档，并在发布说明中标注提交号

### Sources and submodules

- DSP core from [NeriPlayer Android](https://github.com/cwuom/NeriPlayer)
  - Location: [`src-tauri/crates/neri-playback/native/dsp/`](src-tauri/crates/neri-playback/native/dsp/README.md)
  - Use: C++ equalizer, tone, spatial, and dynamics processing; the source commit and desktop extensions are listed in that README
  - License: GPL-3.0, see the directory's [LICENSE](src-tauri/crates/neri-playback/native/dsp/LICENSE); the upstream USB-path alternative grant does not apply
- [FFmpeg](https://ffmpeg.org/) public headers and shared libraries
  - Location: [`src-tauri/crates/neri-playback/native/ffmpeg/include/`](src-tauri/crates/neri-playback/native/ffmpeg/README.md) (headers); the shared libraries ship only in installers
  - License: LGPL-2.1-or-later per each header's notice; the shared libraries are built without GPL / nonfree components, and Releases attach the corresponding sources and build scripts
- Challenge solver scripts generated by [yt-dlp/ejs](https://github.com/yt-dlp/ejs)
  - Location: [`src-tauri/crates/neri-platform/src/api/youtube/assets/`](src-tauri/crates/neri-platform/src/api/youtube/assets/README.md)
  - License: Unlicense; the bundled Meriyah is ISC and Astring is MIT, as stated in the file headers
- [applemusic-like-lyrics (AMLL)](https://github.com/cwuom/applemusic-like-lyrics)
  - Location: Git submodule `vendor/applemusic-like-lyrics`, bundled into the frontend build
  - License: AGPL-3.0, see `LICENSE` inside the submodule
- [YAQMC/qm-api-rs](https://github.com/YAQMC/qm-api-rs) (crate `qqmusic-api`)
  - Location: `[workspace.dependencies]` in `src-tauri/Cargo.toml`, a git dependency pinned to commit
    `75f6e4d392f6d3e64608fb48e2480fb0087009e3`; used by `neri-platform` and the host crate
  - Use: the library implements the QQ Music and WeChat OAuth protocols, credential renewal,
    playlist/library reads, and stream signing; this repository only adds the auth-window
    orchestration, navigation allowlist, callback validation, and renewal scheduling
  - License: GPL-3.0-or-later; the crate bundles MIT-licensed derived work (QMCDecode, by 程序猿老龚)
    whose provenance is documented in that repository's THIRD_PARTY_NOTICES.md
  - Distribution: binary releases ship the complete source archive of that pinned commit under
    GPLv3 section 6, with the commit id named in the release notes
